Example

Suppose you have:

Lambda A:
A1 (warm container) → Cert-V1
A2 (warm container) → Cert-V1

Lambda B:
B1 (warm container) → Cert-V1
B2 (warm container) → Cert-V1

Now the certificate changes:

Cert-V1 → Cert-V2

EventBridge triggers:

Lambda A → one invocation → A1 → Cert-V2 ✅
Lambda B → one invocation → B1 → Cert-V2 ✅

But the other warm containers may still have:

A2 → Cert-V1 ❌
B2 → Cert-V1 ❌
Why?

Because one Lambda invocation is handled by one execution environment. The trigger is not broadcast to all existing warm containers, and each warm container has its own separate memory.
