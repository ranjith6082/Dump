If you have two Lambda functions, and each currently has 10 warm execution environments, then:

After EventBridge is triggered/reloaded

If EventBridge invokes both Lambdas, AWS can use their existing warm containers if they are still available.

When a new request comes

Case 1: A warm container is available
➡️ Lambda uses one of the existing warm containers.
➡️ No cold start.

Case 2: All warm containers are busy
➡️ Lambda creates a new container to handle the additional request.
➡️ This can cause a cold start.

Simple example

Lambda A has 10 warm containers:

5 containers are currently busy
5 containers are idle/warm

A new request comes → one of the 5 available warm containers can be reused.

But if all 10 are busy and request number 11 arrives concurrently → AWS may create a new execution environment.

Important: EventBridge does not normally force all existing warm containers to restart or refresh. Warm containers can continue being reused until AWS eventually retires them.
