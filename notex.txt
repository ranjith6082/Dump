result = null

API Request
    ↓
Cache = NULL
    ↓
Get Lock
    ↓
Check Cache Again
    ↓
Still NULL
    ↓
Call Secrets Manager
    ↓
Load Certificate
    ↓
Update Cache
    ↓
Use Certificate

Expected result: ✅ Success.

Example:

Cache = Available

Expiry = 31-12-2026

FALSE

    ↓

    ↓

    ↓

3. Today equals expiry date

Example:

Today = 31-12-2026
Expiry = 31-12-2026
today >= expiryDate
TRUE

Cache Available
    ↓

    ↓

    ↓
Update Cache

Expected result: ✅ Refresh certificate.

4. Today is after expiry date
Today = 01-01-2027
Expiry = 31-12-2026
today >= expiryDate
TRUE

Expected result: ✅ Fetch latest certificate.
