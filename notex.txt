Initial state

You have one Lambda with 3 warm containers:

Lambda A

Container 1 → Cached Certificate V1
Container 2 → Cached Certificate V1
Container 3 → Cached Certificate V1
Certificate is updated
Secrets Manager
V1 → V2
       │
       ▼
EventBridge
       │
       ▼
Refresh Controller Lambda
       │
       ▼
Invoke Lambda A
What you expect
Destroy V1 containers
        ↓
Create new containers
        ↓
All containers use V2
What actually happens

Lambda may reuse an existing container:

Refresh invocation
       ↓
Container 2
       ↓
Reload certificate V2

Now:

Container 1 → V1 ❌
Container 2 → V2 ✅
Container 3 → V1 ❌

A new API request can still go to:

New Request
    ↓
Container 1
    ↓
Uses V1 ❌
Main problem

Your refresh request cannot guarantee that all existing warm containers are refreshed.

Each Lambda warm container has its own separate cache and memory.

Simple conclusion
EventBridge → Detect certificate update ✅

Refresh one Lambda invocation → Possible refresh of one container ✅

Refresh ALL warm containers → Not guaranteed ❌

Destroy ALL warm containers → Not directly supported ❌

So for your requirement, EventBridge is good for detecting the certificate update, but it alone cannot guarantee that every warm container immediately switches from V1 to V2.
